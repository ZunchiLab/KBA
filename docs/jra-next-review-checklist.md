## 次回から必須の判断

1. **未知は順位の下端へ自動配置しない。** 比較できる集団内の順位と全頭の総合判断を区別する。直近4走に同条件がないことを、全生涯の未経験や不適性と呼ばない。可能なら全戦歴・調教等の事前公開材料を補う。取得できなければ保留を残す。数値保留馬が既知馬より勝てる可能性を比較できないレースでは強い本線を出さない。
2. **直近の現級好走を平均値だけで埋没させない。** 京都7R①は直近ダ1800現級2着0.4秒差があったが総合12位。採用馬⑪と同じ項目で比較する。古い凡走も残すが、その平均点だけで最新の根拠を消さない。係数を今日の結果に合わせて変更しない。
3. **単勝には勝ち切る比較が必要。** 京都1R⑭と東京8R⑥はともに2着。圏内の安定性・直近2着だけで単勝へ接続しない。有力な逆転相手それぞれに、なぜ先着を期待するかを根拠走付きで説明する。説明できなければ単勝を見送り、ワイド等は別途価格と費用を確認してから判断する。
4. **展開の両側を買い目へ接続する。** 京都11Rの本線は差し⑫を全点共通軸にし、事前に認識した前残り候補⑪を外して全敗。先行馬の数・過去の平均位置だけで前崩れを決めない。各馬の前に行ける幅、控えられる幅、コース変更を確認する。別展開で全点が同じ軸に依存するなら、それでも維持する理由か見送る条件を明示する。
5. **相手の除外を採用馬との直接比較で決める。** 京都9R⑨2着・12R⑤1着でも本線は全敗。人気や高い表示価格だけで相手を決めず、現級・近似距離・位置取り・状態・級と距離の変更を同じ項目で比較する。候補を無制限に追加する改善はしない。
6. **保存価格と購入条件を区別する。** 朝の価格で対象か、直前に実行したか、最終払戻を別に保存する。唯一的中の東京11R④–⑤は朝4.0〜4.6倍、下限4.0倍、払戻380円/100円。最終払戻だけで購入時の条件違反を推定しない。別案の後出し選択と余剰予算の再配分は禁止。
7. **新馬の市場参考を独自予想の成績へ混ぜない。** 価格更新時には市場参考の順位・値も同じスナップショットへ揃える。参考◎を独自◎として数えない。障害の暫定評価も別に集計する。自信度・波乱度を校正済み確率と表示しない。

## 実装した公開前ゲート

`scripts/check_jra_forecast.py`は値の整合性と、以下の明示的比較記録を検証する。2026-10-11以降のJRA新規公開では`publish_prediction.ps1`が`--strict`で呼び、未完了なら公開前に停止する。過去の固定予想と地方公開は変更しない。これは書式・記録を検査する機能で、自由文の全意味・体調・実力・期待値・的中を自動検証するものではない。

各レースの`analysis.preflight_review`に保存する:

```json
{
  "single_win_edge": {
    "number": 1,
    "rival_numbers": [2, 3],
    "why_win_not_only_place": "圏内安定性とは別の先着比較を、各相手に対して記述",
    "evidence_refs": ["採用馬の実際のrun_id", "相手の実際のrun_id"]
  },
  "exclusions": [{
    "number": 2,
    "compared_with": [1],
    "reason": "双方を同じ項目で比較した除外理由",
    "unknown_is_not_inferior_reason": "指数保留馬の場合、未知を低能力に変換せず優先差を説明。未解決なら本線を見送る",
    "evidence_refs": ["除外馬の実際のrun_id", "採用馬の実際のrun_id"]
  }],
  "scenario_checks": [
    {"scenario": "main", "response": "keep", "reason": "本線展開での買い目採否", "evidence_refs": ["実際のrun_id"]},
    {"scenario": "alternate", "response": "skip", "reason": "別展開での見送り条件", "evidence_refs": ["実際のrun_id"]}
  ],
  "fact_checks": [{"number": 1, "run_id": "実際のrun_id", "field": "resolved_class", "expected": "1勝クラス"}]
}
```

単勝本線がなければ`single_win_edge`は不要。本線採用馬は除外記録不要。除外比較の対象は、指数保留、勝つ／圏内候補、指数上位3頭、直近の現級・近似距離3着以内、条件戻り候補。双方の根拠走参照が必要。レース本線を見送った場合は比較を済ませたと偽装せず、見送り理由と保留を表示する。

根拠照合は本文の級だけでなく、`distance`・`finish`・`iso_date`等の実際の過去走フィールドについて必要分を追加し、自由文の該当文も手作業で原文へ照合する。構造値の一致だけで自由文まで正しいとは保証しない。

確認コマンド: `python -X utf8 scripts/check_jra_forecast.py 予想JSON --strict`。

# 新馬の4役割参考指標（2026-10-31）

ユーザー指示「新馬戦も指標を、できるところまで」に対応。新馬を一括して空欄にせず、本人の実走とは別に、確認済みの関連実績を数値参考として表示する。現行は `jra-debut-cohort-v1`。独自の実戦能力測定・着順確率・期待値ではない。父名や厩舎名の印象だけで加点しない。

## 入力と時点

`scripts/jra_debut_corpus.py` の `load_saved_observations(KBA, before_date=対象日)` で保存予想と公式確定結果を突合。名前・馬番・元予想参照・確定全件を照合し、入力ファイルSHA、出馬表と結果の原文SHA/取得時刻を保持する。現在の資料は保存8日39新馬戦529出走例のみ。全国通年の統計ではない。

`scripts/jra_role_indices.py` の `apply_indices(..., debut_observations=observations)` へ渡す。各対象日より前730日以内、同じ芝/ダート種別、入力確認時点以前に取得済みのカードと結果のみ使用。当日の他レース結果も使用しない。対象馬本人の過去出走が見つかれば新馬の前提を再確認して停止。取消・除外は数値対象外。非完走・不正着順/頭数/距離、未確定・時点後の資料は理由付きで対象外。

## 計算

父・厩舎・騎手が一致する過去の新馬出走例を抽出。一致の重みは父0.4・厩舎0.35・騎手0.25の和（最大1）。同じ出走例は複数一致しても一度だけ集計。開催日の近さ `exp(-日数/180)` と距離差 `1/(1+距離差/400)` を掛ける。異なる種別の新馬を混ぜない。

各出走例に対し1着・2着ちょうど・2着以内・3着以内の該当を別計上。頭数nの基準（1/n・1/n・min(2,n)/n・min(3,n)/n）を引き、100倍した差を集計。これは頭数差の粗い比較基準で、今回の確率ではない。加重差の合計を（重み合計＋4）で割って少数例を平滑化する。

同一R/役割内で相対化（±3まで）。資料量補正は `min(重み合計, 有効例数)/(min(重み合計, 有効例数)+8)`。有効例数は重み合計²/重み二乗和。表示は `50+10×相対差×資料量補正`。補正後の再標準化はしない。全く関連例がない馬は差を作らない50と「材料未充足」を表示し、平均能力を確認した値と呼ばない。同じレースでも全頭に材料がなければ、指標順を有効な予測順として成績へ数えない。

係数は未学習の仮説で今回の結果へ最適化していない。複数の関連例も互いに無相関とは証明しておらず、資料量補正は信頼確率ではない。市場のオッズは計算に使わない。新馬の4値は既走馬の本人実績と区分し、他レースとの絶対比較をしない。

## 調教・母系と表示

現状は `method: debut_cohort_reference`、`estimator_version`、`matched_starters`、`weighted_sample_mass`、`components`（各例の結果・一致項目・重み・役割別差・出典）を保存。`training_status: 未採点`、不足項目を明示。本人0走と関連出走例数は別表示。1着/2着ちょうど/連対/3着内の4値と8通りの並べ替え（保存単勝人気順を追加）へ接続済み。

10/28–29のJRAレーシングビュアー公開一覧では10/31新馬54頭中9頭の掲載名を確認したが、時計・負荷・併せ馬・手応えの全頭比較は未完了。掲載の有無で採点しない。開催後に取得した資料を過去の入力へ混ぜない。母/きょうだいの網羅評価、実測の調教成分は未実装。確認できていない時計を空欄埋めのために作らない。今後追加する場合は日付・コース・距離・馬場・負荷・出典と比較可能な集団を保存する。

## 並び順の診断定義

`scripts/jra_rank_coverage.py`：取消除外を除き、各指標降順・総合順位昇順・保存単勝オッズ昇順。同点は画面と同じ朝総合順位→馬番、欠損末尾。公式3着以内の全馬の表示順位の最大が「3頭がそろう必要頭数」。同着で4頭なら全4頭を保持する。上位3/4/5/6/7頭ごとの全包含と捕捉頭数を公開。掲載馬券の的中とは別。

8開催日の既走平地193Rでは、上位5頭への全包含は朝人気69・総合印順65・3着内指標57、上位7頭は119・110・99。上位3頭だけなら3着内指標16が最多だが、比較範囲を選んで全般的優位性と呼ばない。前回集計は同点を馬番で処理していたため、画面に合わせた今回の値と境界の結果が少し異なる。数値の差をモデル改善と扱わない。

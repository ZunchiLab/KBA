# JRAの4役割実績指標 v2（2026-10-31セルフレビュー）

現行は `jra-role-relative-v2`。1着・2着ちょうど・連対（2着以内）・3着内の実績を、同じレース・同じ役割の中で比較する補助指標。未学習・未校正。未来の着順確率・絶対能力・期待値ではない。人気基準を上回る全般的優位性は示していないため、指標だけの機械選馬に使用しない。

## v1で問題だった点

過去2着1回で2着指標100になり、資料の薄さを主表示へ反映していなかった。独自比較できない障害馬に市場値を4項目へコピーした点も不適切だった。v1の原本・見本・成績は保持し、修正版を別ファイルで示す。単なる上限99への変更ではない。

## 集計と相手比較

JRA公式全掲載履歴と出馬表を競走IDで突合。今回より前730日以内、完走・確認済みJRAの級・頭数・距離・馬場種別がある同種馬場の直近8走までを使用。好走だけを抜き出さず、1走1回集約。未解析履歴を好走補足の分母へ代用しない。級不明・JRA以外・不正値は理由を保存して採点外。別馬の履歴・後から解決した級・確認時点後の履歴は停止。

内部の各走実績値はv1と同じ仮の着差/着順関数。着順値は100−75×(着順−1)/(頭数−1)、着差値は1着100・それ以外100×exp(−着差/(0.55×sqrt(距離/1200)))。1着は着差75%と着順25%、2着ちょうどは2着との着順距離の指数関数、連対は着差40%と2着以内実績60%、3着内は着差20%と3着内実績80%。着差欠損はその成分を使わず、0秒で埋めない。JRA内の級仮補正は下級−12/段階・上級＋4/段階、−36〜10。これらは学習した係数ではない。

走の重みはexp(−日数/180)/(1＋距離差/800)、同場1.15倍。内部実績値を同じレースの比較可能な馬の平均・標準偏差で相対化する。異馬場参考・市場のみの馬は比較基準の集計へ混ぜない。比較可能な馬が一頭だけ/同点なら差を作らず基準50。

表示値＝50＋10×相対差（±3まで）×資料量補正。資料量補正＝有効走数/(有効走数＋3)×exp(−最新走からの日数/365)。異馬場はさらに1/4。有効走数は重みの二乗和から計算し、同じ競走は独立証拠として二重に数えない。補正後に再標準化しない。再標準化すると全頭1走のレースで抑制が打ち消されるため。係数3や尺度10も仮説であり校正済みの信頼度ではない。

資料が少ない・古いことを低能力と同義にせず、50側へ寄せる。50は平均能力や今回条件への適性を確認した意味ではない。異なるレース・役割間で点差を絶対能力差として比較しない。内部実績のraw_valueに100があっても、主表示のvalueは満点・確率ではない。

## 参考と欠損

平地で同種の実績がなければ異馬場参考を明示して補助値を残す。障害へ平地成績を流用しない。独自比較が未解決なら保存単勝オッズだけを別欄へ表示し、4指標を同値コピーで埋めない。新馬・取消の独自指標は理由付きnull。「~」は使わず、参考の種類・採点に使った走数・資料の薄さを馬名の下に表示する。

計算は `apply_indices(race, as_of=..., history_by_number=...)`。入力確認時点と実際のcomputed_atを分離し、結果後の見本を朝へ遡らせない。元の旧score/rank/mark・買い目・根拠は変更しない。新規作成は4指標を計算してから最終固定時刻を確定する。

`role_indices`に version、experimental、comparison_scope、computed_at、input_cutoff_at、method、reason、source_refs、components、omitted_runs、runs/effective_runs/reliability_weight、first/second/top2/top3 の value/raw_value/reference を保存。market_referenceは保存単勝オッズと出典で、4指標へ代入しない。

## 手順と公開検査

11/1以降はv2の定義・4項目・資料量補正・相手基準・実走・時点・非有限値・重複をstrict検査。`analysis.role_index_usage_review` にmode=auxiliary_only、benchmark_edge_unproven=true、independent_comparison_reasonを保存。

有力な除外馬はpreflight_review.exclusions[].best_case（run_id/why_relevant）とpeer_case（number/run_id/why_prefer）、双方のevidence_refsを記録する。市場上位、指数上位、条件戻り、役割別候補を対象。全点共通馬がある本線はdependency_reviews[]へ plan_id/mandatory_numbers/without_core/retained_reason/evidence_refs を保存し、共通馬なしの有力な二頭/三頭を比較。必要頭数が存在しない場合だけ no_feasible_without_core_reason を記録。記録の存在は判断の正当性を保証しない。

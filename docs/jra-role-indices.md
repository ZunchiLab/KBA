# JRAの4役割指標（2026-10-31実装、次回の新規予想から）

ユーザー希望により1着、2着ちょうど、連対（2着以内）、3着内を別に表示し、それぞれで並べ替える。0〜100の実績比較指数。未学習・未校正で、着順確率・的中率・収益率ではない。2着ちょうどは過去の着順が2着に近い実績を表す仮の指標で、未来の2着確率を推定したモデルではない。

実装：`scripts/jra_role_indices.py`の`apply_indices(race, as_of=..., history_by_number=...)`。元データを変更せず各馬の`role_indices`へ追加。旧`score/win/place/model_rank/rank/mark`と買い目は不変。新規作成では全掲載履歴を渡し、各レースの計算後に最終固定時刻を確定する。`as_of`は入力の確認時点、`computed_at`は実際の計算時刻で別。結果後の表示見本では朝へ計算時刻を遡らせない。

## 集約と式

JRA公式全掲載履歴と出馬表の過去走を競走IDで突合。今回より前730日以内の完走、確認済みJRA内の級、頭数、距離、馬場種別を使う。同種馬場の直近8走までを選び、好走だけを抽出しない。古い補足好走だけを分母に使わない。1競走を1回だけ集約。級不明・JRA以外・非完走は理由とともに除く。地方/海外をJRAの共通点へ未検証換算しない。

各走の基本値：着順値=100−75×(着順−1)/(頭数−1)。着差値は1着100、それ以外100×exp(−着差/(0.55×sqrt(距離/1200)))。着差欠損を0秒にせず、その成分を使わない。1着指数=着差75%＋着順25%（着差なしは着順値）。2着ちょうど指数=100×exp(−abs(着順−2)/max(1,頭数/5))。連対用実績値=100×exp(−max(0,着順−2)/max(1,頭数/4))、3着内用実績値は閾値3と分母max(1,頭数/3)。連対指数=着差40%＋連対実績60%、3着内指数=着差20%＋3着内実績80%。着差なしは各実績値だけを使う。

級の仮補正は従来と同じ下級−12/段階・上級＋4/段階、範囲−36〜10。0〜100へ制限。走の重みはexp(−経過日数/180)/(1＋距離差/800)、同場1.15倍。係数は人が定義した仮説で本日結果へ最適化していない。馬場の良/重の優劣・不利・調教・展開・斤量の学習モデルではない。四つの指標は共通の実走を使うため、独立した四つの裏付けとは数えない。

## 欠損と参考

- 直近4走に材料がなくても古い同種馬場の全掲載履歴へ広げる。
- 平地で同種馬場の材料がなければ、他の平地種別を`cross_surface_reference`として低い資料充足度と`~`付きで表示。今回条件の適応を証明せず、減点0や最低能力へ置き換えない。障害へ平地実績を流用しない。
- 比較可能な級・実走がなければ、確認時点付きの市場値を`market_reference`・「4役割未分離」として別表示。100×最小単勝/保存単勝の共通値で、役割の差を推定したとは言わない。市場値もなければ理由付きnull。
- 新馬は独自4指標を捏造しない。市場参考値は旧欄へ保持。取消・除外は対象外。
- `components[]`に競走ID・日付・級・着順・着差欠損・距離・重み・4寄与、`source_refs`、`omitted_runs`、`runs/effective_runs/confidence`を保存。充足度は主観的な資料の評価で的中確率ではない。

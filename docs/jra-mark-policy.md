# JRAの印を頭数と買い目に合わせて絞る

2026-10-26のユーザー指示：「出走馬数に応じて印の数も変動」「できるだけ最小限で的中」。次の新規JRA予想に適用。過去の固定予想・結果・印は変更しない。全レースを広く比較する希望は維持し、購入レース数の削減や賭け金の増額を指示されたとは解釈しない。

| 取消・除外を除く出走予定頭数 | 印を付ける上限の目安 |
|---|---|
| 6頭以下 | 2頭 |
| 7〜9頭 | 3頭 |
| 10〜12頭 | 4頭 |
| 13〜15頭 | 5頭 |
| 16〜18頭 | 6頭 |

目安は頭数の3分の1切上げ、最低2頭（実在頭数まで）。的中確率から求めた最適値ではない。数を埋めず、2頭で足りるなら2頭、独自比較ができなければ印保留も可能。混戦で削れない場合は、超過理由と増える点数・費用を明記し、数の目安を守るためだけに有力馬を切らない。

## 選定と買い目

- 全頭の総合順位・指数・根拠・欠損は残す。印は人手で選んだ購入候補の範囲として絞り、指数や順位から自動的に上位N頭を採用しない。総合の◎と券種の連対軸・圏内軸は別に判断する。
- 印外にする境界2頭、数値保留、指数上位3頭、条件戻り候補を、採用した印候補と同じ条件・級・近況・根拠走で比較。未知を自動的に最下位へ置かず、説明が未解決なら保留を残す。
- ワイド1点・2点・3頭BOX、馬連1点・少数フォーメーション・従来5点、三連複の実候補数を比較する。従来の5点/12点を作るために4頭/7頭を埋めない。希望の買い方は優先比較するが機械変換しない。
- 本線の全買い目に現れる馬には印を付け、印の数と購入範囲を食い違わせない。参考・入替え案だけの馬は全頭評価に残せるが、別案を本線へ自動追加しない。買い目の組替えは人手で発走前に実施する。
- 印が少なくても馬券は自動生成しない。軸・相手・群の制限、全点・費用・価格下限・確認時刻を保存する。価格未達点だけを古い案から削る部分購入にはしない。1点案も独立した事前比較と価格を持つ。
- 頭数・取消が変わったら境界を再比較し、発走前の新しい版へ保存する。印を減らすこと、点数を減らすこと、的中率・回収率を上げることは別に測定する。

## 実装・保存項目

共通関数は`scripts/jra_mark_policy.py`。`suggested_limit(n)`は目安だけを返す。`apply(race, numbers, reviewed_at=..., reason=..., boundary_reviews=..., exception_reason=...)`は呼出側が人手で選んだ馬番から別コピーを作り、印と`analysis.mark_selection`だけを追加・変更する。順位・指数・根拠・買い目は変更しない。自動選馬や学習済みモデルではない。

記録は`policy: field-size-v1`、`field_size_at_review`、`suggested_limit`、`marked_numbers`、`reviewed_at`、`reason`、`boundary_reviews[]`（`number/compared_with/reason/evidence_refs`）、`exception_reason`。境界比較の参照は双方の実際の根拠走を使用する。

`check_jra_forecast.py --strict`は2026-10-26以降の新規JRAで、記録の存在・頭数と印の一致・本線の無印馬・発走前時刻・目安超過理由・境界比較を検査する。既存の公開コマンドから接続済み。共通compact描画は新しい記録がある場合だけ「印N頭」と選定理由を表示する。旧JRA・地方の印を自動変更しない。

8件の単体テスト、既存ゲート20件、形式検査CLIの不足時終了1、既存10/25表示が不変であることを確認した。検査は理由の記録と参照を確かめるもので、文章全体の妥当性・能力差・最適頭数・収益性を保証しない。次の未知開催の人手選定・実公開・効果確認は未実施。

## 10/25で分かった限界

独自平地30Rで旧印は計239頭。上の目安で固定順位の上位だけを残す開催後診断では136頭になるが、候補内に公式ワイド的中組合せを含むレースは27→18、三連複は20→3。候補包含は実際の掲載券の的中ではない。単に上位を切る方法の改善実証にはならず、境界の選馬と券種選択を先に見直す必要がある。

朝価格達成本線は21R71点7100円→1650円、4R的中、23.24%。同じ21R同費用の朝人気1850円・指数1710円も赤字。実購入・直前条件は未確認。詳細は[全36Rの反省](../predictions/report_20261025_jra_review_v1.html)。今日の結果へ係数・価格下限を合わせず、次回も旧固定順位と人気基準を事前保存して比較する。


## 2026-10-31更新：3頭捕捉を先にする（11/1以降）

ユーザーは「印は少なくしても馬券内の3頭を全部入れてほしい」と希望。今後の目的は印の削減より上位3頭の捕捉。全レースで3頭を必ず含む保証はできない。購入点数を絞ることと印候補の範囲を分ける。

新規は`coverage-first-v2`。参考頭数は従来の3分の1切上げを残すが、最低3頭（実在頭数まで）。頭数を守るためだけに有力候補を削らない。超過は必要な実績・別展開・費用への影響を説明し、印全頭を自動でBOX購入しない。人手選定を維持し、上位N頭・指標順から印へ機械変換しない。

`analysis.mark_selection.coverage_review`に`objective: capture_all_top3`、`not_guaranteed: true`、`candidate_groups.first/second/top2/top3`、`scenario_groups[]`（主・別展開の各3着内候補と理由）、全体の`reason`を保存する。独自印を出すときは4役割と別展開を比較。本線があるなら少なくとも3頭の印候補を比較する。各役割の候補を印外へ置く場合も双方の根拠走を持つ境界比較が必要。独自評価不足の新馬などは印なし・見送りを維持できる。

`jra_mark_policy.apply/audit_race`とstrict公開検査へ接続。10/31以前は旧方針・印・買い目を保持。検査は記録の整合性であり、候補の正しさ・全3頭捕捉・利益の保証ではない。

10/31の独自19Rでは印73頭で上位57頭中30頭、3頭とも含むのは2R。同じ各Rの印頭数の朝人気は33頭・2R、旧指数は28頭・1R。少なくするだけでは不十分だった。新方針の未来の効果は未確認。
